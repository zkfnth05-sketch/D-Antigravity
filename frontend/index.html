수동 조작 없이 100% 무인 자율 파이프라인으로 코드를 설계·비판·작성·검증·배포합니다.

📜 안티그래피티 무인화 절대 수칙 (Rule Engine)

이 수칙들은 모든 딥시크 AI의 System Prompt에 항시 강제 주입되며, 임의 변경이나 무단 우회가 불가능합니다.

강제 적용 1. 🧩 [신규 기능 개발 시 모듈 분리 원칙]

기존 파일에 무리하게 코드를 덧붙이지 않고, 독립된 컴포넌트/유틸리티/서비스 파일로 명확히 분리하여 기존 안정성 훼손을 방지합니다.

강제 적용 2. 📢 [사전 원인 분석 및 선(先) 설명 의무] (코드 덤프 금지)

대화창에 무의미하게 코드를 내뱉지 않으며, 반드시 근본 원인을 먼저 한국어로 설명하고 [3줄 핵심 브리핑]만 대화창에 말합니다. 코드는 디프 에디터로 격리 전송됩니다.

강제 적용 3. 🔍 [코드 전수 조사 및 신중한 답변 원칙]

겉핥기식 추측을 일절 금지하며, 전체 소스 파일과 라인을 처음부터 끝까지 정밀하게 전수 조사한 후 정확하게 답변합니다.

강제 적용 4. 🚫 [무단/암묵적 수정 및 깃 저장 절대 금지]

사용자의 명시적 허락 없이 git commit 및 git push를 실행하지 않으며, 모든 변경 사항은 인라인 Diff로 사전 보고하여 승인을 받습니다.

강제 적용 5. 🛑 [표면적 후처리 땜질 및 눈가림식 코딩 전면 금지]

문자열 치환이나 단순 try-except pass 등 임시 땜질을 배제하고, 데이터 파이프라인의 시작점부터 근본적으로 견고하게 설계합니다.

강제 적용 6. 🤖 [100% 완전 무인 자동화 봇 원칙]

사람의 수동 개입 없이 24시간 365일 실시간 수집부터 4대 SNS 자율 송출까지 무결하게 자율 가동되는 완전 무인 마케팅봇 구조를 절대 원칙으로 합니다.
